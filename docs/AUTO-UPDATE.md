# دليل نظام التحديث التلقائي الآمن (Tauri Auto-Updater)

يشرح هذا الدليل البنية التحتية لنظام التحديث التلقائي المعتمد في **WDS**، وكيفية توقيع الحزم رقمياً والتحقق من سلامتها قبل التثبيت.

---

## 🔐 مبدأ الأمان والتوقيع الرقمي

يعتمد نظام التحديث في WDS على خوارزمية التوقيع الرقمي **Minisign (Ed25519)** عبر إضافة `@tauri-apps/plugin-updater`:

1. **المفتاح العام (Public Key):**
   - مُضمن علناً وبأمان داخل إعدادات التطبيق في `src-tauri/tauri.conf.json`:
   ```json
   "plugins": {
     "updater": {
       "pubkey": "dW50cnVzdGVkIGNvbW1lbnQ6IG1pbmlzaWduIHB1YmxpYyBrZXk6IDJGOTY1QTMzOUMxMUIyNkIKUldScnNoR2NNMXFXTHhpKzJzMEJBMzRBS2dDdkw1dFhNekhxZzRMTzBZZStpdFRGRjVTb3dULzUK",
       "endpoints": [
         "https://github.com/sufyanaser/WDS/releases/latest/download/latest.json"
       ]
     }
   }
   ```

2. **المفتاح الخاص (Private Key):**
   - **سري للغاية:** لا يُرفع أبداً إلى المستودع أو يُضمن في مثبت التطبيق.
   - مخزن حصرياً كسرّ مشفر في GitHub Actions:
     - `TAURI_SIGNING_PRIVATE_KEY`
     - `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`
   - يُستخدم فقط أثناء سير عمل البناء في بيئة GitHub Runner لتوقيع حزم التحديث.

---

## 🔄 مسار عمل التحديث (Update Flow)

1. **اكتشاف التحديث:**
   عند تشغيل التطبيق، تقوم واجهة WDS بفحص الرابط:
   `https://github.com/sufyanaser/WDS/releases/latest/download/latest.json`
   دون تعطيل بدء تشغيل التطبيق أو مقاطعة عمل المطور.

2. **إشعار المستخدم:**
   إذا توفر إصدار أحدث، يظهر إشعار في الزاوية يعرض رقم الإصدار الحالي ورقم الإصدار الجديد وملاحظات الإصدار مع زر "تنزيل وتثبيت".

3. **التحقق من التوقيع والتثبيت:**
   عند ضغط المستخدم على زر التحديث:
   - يتم تنزيل حزمة التحديث وملف التوقيع الرقمي (`.sig`).
   - يقوم محرك Tauri الداخلي في Rust بالتحقق الرياضي من التوقيع باستخدام المفتاح العام المعتمد.
   - إذا كان التوقيع غير صالح أو تالفاً أو تم التلاعب به، **يُرفض التحديث فوراً** ويتم إشعار المستخدم.
   - إذا كان التوقيع صحيحاً، يتم استبدال الملفات التنفيذية بصورة آمنة.

4. **إعادة التشغيل:**
   يتم طلب موافقة المستخدم لإعادة تشغيل WDS لتطبيق الإصدار الجديد، مع الحفاظ الكامل على إعدادات وبيانات الاعتماد المحلية المخزنة.
